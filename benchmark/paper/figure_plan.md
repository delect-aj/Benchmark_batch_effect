# 主图规划（5 个大图）

## 为什么是递进而不是并行

参考的 *Nature Methods* 多任务基准走并行：四类整合（vertical / diagonal / mosaic / cross）互相独立，所以
Fig 2–5 结构完全同构，只换数据切片。

我们的三个文献空白是**依赖关系**，不是并列关系：

1. 没有金标准，排名随指标翻转 → **决定了后面所有结果该怎么读**
2. "移除批次"与"跨研究泛化"结论矛盾 → 要先知道真值才能判断谁对
3. 混杂下方法普遍失效，但没人系统量化 → 需要前两步建立的判据

所以：先立判据（Fig 2）→ 用真值检验判据（Fig 3）→ 在混杂梯度上施压（Fig 4）→ 落到下游后果与选型（Fig 5）。
每一图回答一个科学问题，后一图的解释依赖前一图的结论。

## Fig 3 — Q2：真值下究竟发生了什么

**说明什么**：代理指标好看 ≠ 真的恢复了真相。这是全文最硬的一图。

| 面板 | 内容 | 形式 |
|---|---|---|
| **a** | Mock 偏倚的移除：`jmbc_extraction` 纯 mock 的 per-taxon log2(观测/真值)，raw vs 各方法；按革兰型/基因组大小排序 | 热图或并排点图 |
| **b** | 到已知组成的 Aitchison 距离：raw 与各方法，两个 mock 数据集（jmbc + salim_pig）分面 | 条形/点图 |
| **c** | **Null 数据集 `jmbc_library`**：同一份 DNA mock 过 28 种建库方案，各方法制造出多少虚假结构（残留 batch R² 与虚假 DA 数） | 条形图 |
| **d** | 模拟中与 Oracle 的接近度：Mantel r 与 per-taxon Spearman，按方法 | 散点或箱线 |
| **e** | **系统性 vs 非系统性偏倚**：按 `affected` = 0.1/0.5/1 分层的表现 —— 乘性假设成立与否是否决定成败 | 分组条形 |
| **f** | 代理指标 vs 真值的一致性：x = batch R² 下降，y = 到 Oracle 的距离改善，看二者是否同向 | 散点 |

**排版**：a 左上（~90×60 mm）；b + c 右上（各 ~85×30 mm）；d + e + f 下排三格（各 ~58×55 mm）。总高约 125 mm。

**转补充**：mbqc 的重复一致性（同标本距离 before/after）—— 第三种真值，但与 a/b 结论同向，放补充；
brooks 的同类分析（仅 2 块板，统计力弱）。

> e 的依据来自我们自己的实测：salim_pig 的偏倚向量跨 3 种建库方式 r = 0.992–0.993（高度系统性），但
> jmbc 的 9 种提取方案中有 2 种明显偏离（r ≈ 0.56–0.84）。所以"非系统性"不是假想情形。

## Fig 4 — Q3：混杂梯度上的断裂

**说明什么**：本文的核心增量。混杂不是"注意事项"，而是决定方法可用与否的主变量。

| 面板 | 内容 | 形式 |
|---|---|---|
| **a** | **主面板**：性能 vs Cramér's V（0/0.3/0.6/0.9/1），每方法一条线，batch removal 与 bio preservation 双 y 轴或上下两栏 | 折线，整宽 |
| **b** | **过校正指数**：生物信号损失 / 批次信号损失 的比值沿梯度变化 | 折线 |
| **c** | **泄漏检验**：把表型打乱后再校正，方法是否仍"保留"了一个并不存在的表型 | 条形图（已有 `conqur_permcov` 作为该设计的原型） |
| **d** | 真实数据锚点：`mbqc`（V = 0）与 `hivrc_16s`（天然混杂，2 个研究无对照）上的同一度量，检验模拟是否外推得上 | 并排点图 |
| **e** | **断裂点**：每方法生物信号保留率跌破阈值时的 V 值 | 横条排序图 |

**排版**：a 整宽（~180×70 mm）；b + c 中排（各 ~88×45 mm）；d + e 下排（各 ~88×45 mm）。总高约 165 mm。

**转补充**：按批次数（2/5/10）、每批样本量（20/50/200）、批次不平衡分层的梯度曲线；Percentile Normalization
在无对照批次上的失败记录（它在 mbqc 和 jmbc_library 上会直接报错，这是**方法适用性结论**，正文一句话带过即可）。

## Fig 5 — Q4：下游后果与选型

**说明什么**：回答"批次移除得好是否等于下游更好"，并交付可用的选型建议。

| 面板 | 内容 | 形式 |
|---|---|---|
| **a** | DA 推断：FDR（对名义水平）、power、average precision，按方法 | 三联点图 |
| **b** | **Null 场景**（`da_prop = 0`）：各方法的 I 类错误率与假阳 DA 数 | 条形 + 名义水平参考线 |
| **c** | 跨研究预测 LOSO auROC：转导式 vs 归纳式两种设定并列 ⚠️ **需补实现** | 箱线图 |
| **d** | **矛盾是否存在**：batch-removal 秩 vs DA 秩 vs LOSO 秩 的三方一致性 | 平行坐标或秩-秩散点 |
| **e** | 实用性：运行时间、峰值内存、失败率 | 气泡图 |
| **f** | **选型建议**：按研究目标（可视化 / DA 推断 / 预测建模）× 混杂程度，给出 top-3 | 决策表（仿参考文献 Fig 6，但压缩成表） |

**排版**：a 整宽顶部（~180×40 mm）；b + c 中排（各 ~88×45 mm）；d + e 下排（各 ~88×40 mm）；
f 底部整宽（~180×45 mm）。总高约 180 mm。

**转补充**：完整决策树（参考文献 Fig 6 那种大图，我们放补充）；每个数据集的 LOSO 明细；各方法的失败原因列表。

> d 是对文献矛盾的直接裁决。如果三种秩高度一致，说明 ConQuR 原文与 DEBIAS-M 的分歧来自数据集而非指标；
> 如果不一致，则说明**"批次移除"作为单一判据是不充分的**，这会是本文最强的结论句。
